# glyospalettes: Color Palettes Inspired by Glyos Colorways

Color palettes based on the named production colorways of the Glyos
System Series toy line by Onell Design, plus ggplot2 color and fill
scales.

## Details

Start with
[`glyos_palette()`](https://bmaitner.github.io/glyospalettes/reference/glyos_palette.md)
to pull colors from a colorway,
[`glyos_palette_names()`](https://bmaitner.github.io/glyospalettes/reference/glyos_palette_names.md)
to list the available colorways, and
[`scale_colour_glyos()`](https://bmaitner.github.io/glyospalettes/reference/scale_glyos.md)
/
[`scale_fill_glyos()`](https://bmaitner.github.io/glyospalettes/reference/scale_glyos.md)
to use them in ggplot2. Run
[`glyos_show_palettes()`](https://bmaitner.github.io/glyospalettes/reference/glyos_show_palettes.md)
to see every palette at once.

Hex values are approximations curated from product photography and from
Onell Design's published color descriptions. glyospalettes is a fan
project and is not affiliated with or endorsed by Onell Design.
