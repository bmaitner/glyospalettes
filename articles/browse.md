## Suggesting changes

Every palette here is an approximation read off a photograph, so
corrections are welcome. Each card links to a prefilled GitHub issue
form:

- **Suggest a change** if a color is wrong, missing, or should be
  removed. Say which hex codes you would add, change or drop and why; a
  photo of the figure under neutral light is the best evidence.
- **Submit a cleaner photo** if you have a shot of the figure on a plain
  background. Cleaner photos let the color sampling run without picking
  up rocks, tables and studio walls. You can drag an image straight into
  the issue form.
- [Propose a new
  colorway](https://github.com/bmaitner/rglyos/issues/new?template=new-palette.yml)
  if a figure or wave you care about is not covered yet.

You need a GitHub account to open an issue. If you would rather not,
email the maintainer listed in the package DESCRIPTION.
